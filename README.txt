# AOI DATAS · 岳一科技数据资产中枢 V1.2.1

## 本地启动
Windows 安装 Python 3.10 或更高版本，双击 start.bat，访问 http://127.0.0.1:8765 。默认 SQLite；MySQL 可沿用 compose.yaml 和 setup_mysql.py 配置。

## V1.2.1 图片检索调整
- 资料检索只展示图片卡片，不再独立展示工程、资料包或文档。
- 卡片集中显示关联项目、产品、分类、材质、工艺、已确认图片缺陷、工程与视频；可看原图、绑定工程和上传视频。
- 关键词可按关联工程名称/路径、视频名称检索图片；缺陷筛选只依据逐图确认，资料包缺陷单独显示为参考。
- 本次无数据库结构变更，替换程序文件并保留原 data 即可。

## 本次更新
- 产品不再要求填写或显示产品编号；旧 code 仅留作数据库兼容键，新增自动生成。
- 产品分类、材质支持自行维护。产品窗口可快捷新增并立即选中，以后重复使用下拉菜单。
- 分类可选择上级，阻止自身或后代作为上级。
- 检测工程登记本地完整文件/文件夹路径，不需要上传。图片上传窗口可直接新增路径并绑定；已有图片支持单张及批量绑定。
- 图片中点击工程名称后可复制路径，Windows 本机运行支持打开工程文件夹或在资源管理器中选中文件，不自动执行工程文件。Docker/远程访问不支持定位宿主机目录。
- 资料包—缺陷新增支持多选，一个资料包可对应多个缺陷；重复绑定不会新增重复记录。
- 新增 videos 视频资料表（全库 19 张表）。一张图片可关联多个视频，每条视频绑定一张图片。支持上传、播放、拖动、下载、编辑名称和图片关联。
- 单个视频最大 1 GB；推荐 H.264 MP4。MOV/AVI/MKV 等格式可存储，浏览器不支持对应编码时请下载后播放。图片上传窗口维持单文件 256 MB。

## 升级已有数据库
1. 关闭旧服务。
2. 备份整个旧版 data 文件夹（包括 aoi.db、uploads、thumbnails）。MySQL 用户另行备份数据库。
3. 解压新版到新目录，将旧 data 文件夹完整复制到新版目录，不要只复制数据库。
4. 双击 start.bat。程序自动增加 engineering_projects.local_path 和 videos 表，不删除旧数据。升级完成后刷新浏览器。
5. 原来上传的工程文件仍可下载，也可以编辑补录本地路径。

新建 MySQL 数据库可使用 schema.mysql.sql；已有 MySQL 使用程序启动的增量字段更新，账号需有建表和 ALTER 权限。无此权限时由管理员执行 migration-v1.2.mysql.sql 一次，再启动。不要重复执行手动 ALTER。

## 数据与关系
产品分类和材质先维护选项，再在产品里引用；也可边录入边新增。内部 id 自动生成，用于关系绑定，不需要手填产品编号。
视频通过 videos.image_id 关联 images.id；产品通过 asset_products 与该图片资源关联。视频文件保存在 data/uploads，数据库保存路径和关联。视频播放接口支持 HTTP Range。
资料包的多个缺陷分别存入 asset_defects，每个“资料包 + 缺陷”组合唯一；不会自动传播到逐图缺陷。
工程路径可以暂时不存在，点击定位时会检查；请填写运行服务器的电脑上的路径。

## 备份与限制
JSON/CSV/SQL 只含记录，不含图片和视频原文件。完整备份需停服复制 data；MySQL 还需单独备份数据库。删除记录受外键约束，已有依赖时不会删除；删除元数据不会清理磁盘原文件。
本版面向本机小批量资料管理，未包含账号系统、自动 NAS 扫描、以图搜图或百万级分页。默认仅监听 127.0.0.1。

## 验证
运行 python test_app.py 可在独立临时目录验证 CRUD、关系、上传、缩略图、SQL 导出、工程路径绑定、视频传输与 Range、失败回滚及持久化。不会修改用户 data。
